# RIVOLT

RIVOLT — це концепція сучасного сайту про одяг із незвичайними та оригінальними принтами. Основна увага приділена дизайну принтів, візуальній подачі товарів і сучасній streetwear-естетиці. На сайті представлені футболки, кофти та худі з цікавими графічними дизайнами.

## Посилання

- **Живий сайт:** https://splendid-madeleine-daae6a.netlify.app
- **Репозиторій:** https://github.com/Karaputna/rivolt
- **Figma-макет:** https://www.figma.com/design/R3yFo6aGOU5RpBywJLYcgL/RIVOLT.?node-id=0-1&t=UN2rQrE2gUnV6P3o-1

## Технології

- **HTML5, CSS3, JavaScript** — розмітка, стилі та інтерактивність (перемикач теми, мобільне меню, валідація форми).
- **Tailwind CSS v4** — утилітарні класи для сітки та адаптивності.
- **Node.js + Express** — локальний API (`/api/projects`, `/api/contact`) для каталогу та форми.
- **PWA** — `manifest.json` та service worker (`sw.js`) для встановлення сайту як застосунку та кешування основних файлів.
- **Netlify** — хостинг із автоматичним деплоєм при кожному push у гілку `main`.
- **GitHub** — репозиторій і контроль версій.
- **Figma** — макет і дизайн-система.
- **Lighthouse, Chrome DevTools** — перевірка продуктивності, SEO та доступності.

## Деплой

Сайт опубліковано на Netlify і підключено до репозиторію GitHub. Кожен push у гілку `main` запускає автоматичний деплой. Збірка не потрібна (статичний сайт): `Build command` порожній, `Publish directory` — `.`.

> Примітка: розділ «Каталог із сервера» та відправка форми використовують локальний Express-сервер (`localhost:3000`), тому на опублікованому сайті вони недоступні.

## Запуск локально

```bash
# 1. API (порт 3000)
cd server
npm install
node server.js

# 2. Статичний сайт (порт 5500) — в іншому терміналі, з кореня проєкту
npx serve -l 5500
```

Після цього відкрийте http://localhost:5500.

## PWA

- `manifest.json` — назва, іконки 192×192 і 512×512, `display: standalone`, `theme_color`.
- `sw.js` — service worker, що кешує головну сторінку, стилі та скрипт.
- Реєстрація service worker — у `script.js`.

## Tailwind CSS vs звичайний CSS

У Tailwind зручніше швидко стилізувати елемент і робити адаптивність прямо в HTML (наприклад, grid-cols-1 md:grid-cols-3), не перемикаючись між файлами. У звичайному CSS розмітка чистіша, а стилі легше змінювати в одному місці для багатьох елементів. Через довгі списки класів і потребу в збірці Tailwind складніше читати й налаштовувати на початку.
