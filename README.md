## Tailwind CSS vs звичайний CSS
У Tailwind зручніше швидко стилізувати елемент і робити адаптивність прямо в HTML (наприклад, grid-cols-1 md:grid-cols-3), не перемикаючись між файлами. У звичайному CSS розмітка чистіша, а стилі легше змінювати в одному місці для багатьох елементів. Через довгі списки класів і потребу в збірці Tailwind складніше читати й налаштовувати на початку.і
